# TaskNex
TaskNex is a personal todo list and task management application built with Laravel 12 and Livewire 3. Users can organize their work into custom lists, create tasks with optional details like scheduled dates, deadlines, priority levels, and subtasks, and track completion at a glance. The app includes role-based access with a super admin who manages user accounts, alongside soft-delete support for safe recovery of accidentally removed lists and tasks.

Tech stack: Laravel 12 · Livewire 3 · PostgreSQL
